# MY WORK — Productivity Dashboard

A personal productivity dashboard built with **HTML, CSS, and JavaScript** to organize daily tasks, plan schedules, track goals, and manage focused work sessions from one interface.

## 🚀 Live Demo

[View Live Project](YOUR-LIVE-LINK-HERE)

## 📌 About the Project

**MY WORK** is a productivity-focused web application designed to bring common daily planning tools into a single dashboard.

The interface includes separate sections for managing tasks, planning the day, setting goals, using a Pomodoro timer, and managing basic profile settings.

The project was built to practice **DOM manipulation, JavaScript event handling, UI navigation, and interactive web development**.

## ✨ Features

* 📊 **Dashboard**

  * Productivity overview
  * Quick access to different sections
  * Personalized welcome section

* ✅ **Todo List**

  * Add daily tasks
  * Display tasks dynamically
  * Manage personal tasks

* 📅 **Daily Planner**

  * Set start and end times
  * Add scheduled activities
  * Organize tasks according to time

* 🎯 **Daily Goals**

  * Add personal goals
  * Keep track of daily objectives

* ⏱️ **Pomodoro Timer**

  * 25-minute focus timer
  * Start, stop, and reset controls

* ⚙️ **Settings**

  * Basic username/profile settings

* 🧭 **Sidebar Navigation**

  * Switch between different productivity sections without leaving the page
